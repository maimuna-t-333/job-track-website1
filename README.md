# JobTrack 🚀

## Purpose:
A modern, user-friendly job listing platform connecting users with top companies.

## 🔗 Live URL:
[\[Deployed Link Here](https://auth-integration-fef4f.web.app/)]

## 🔧 Features:
- Browse companies and job listings
- Login/Register with email or Google
- Update profile info
- Modal-based job details and apply
- Responsive design (Mobile → Desktop)
- Secure Firebase Auth & Hosting
- Framer Motion animations
- 404 Page and Dynamic Route Titles

## 📦 Used Packages:
- React
- Tailwind CSS + DaisyUI
- React Router
- Firebase
- Framer Motion
